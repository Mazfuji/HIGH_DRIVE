# HIGH DRIVE

`HIGH DRIVE` は、`Hu-BASIC CZ-8CB01` 上で動作する縦スクロール型のカーアクションゲームです。
中央の道路を自車で走り、左右にハンドルを切りながら、路肩・対向車・障害物を避けてスコアを伸ばします。

## 背景

このゲームは、私が小学6年生のときに作ったものです。

当時はまだ自宅にパソコンはなく、パソコン専門店に通っては、店員さんのご厚意で店頭のマシンを使わせてもらい、BASICで遊びながらプログラムを書いていました。限られた時間の中で、簡単なスクロールゲームをいくつも作っていたのを覚えています。

やがて自宅に初代の SHARP X1 を買ってもらえることになり、ようやく自分の環境でじっくりとプログラミングに向き合えるようになりました。それまで店頭で断片的に作っていたアイデアをまとめ直し、このゲームの内容も少しずつ形になっていきました。

完成したプログラムは、徳間書店のコンピュータ雑誌 [テクノポリス](chatgpt://generic-entity?number=0) に投稿し、その後「プログラムポシェット Vol.4」に掲載されました。

掲載時には原稿料として1万円をいただき、当時の私にとっては大金だったそのお金で、株式会社エム・アイ・エー発行の「マシン語プログラミング入門」という本を購入しました。この一冊が、その後の自分のプログラミングの方向性を大きく決めたように思います。

限られた環境の中で工夫しながら作った、小学生の頃の作品ですが、今あらためて見返すと、現在の自分につながる原点のようなものを感じます。

## 起動方法

Hu-BASIC の環境で `high_drive.bas` を読み込み、実行します。

```basic
LOAD "high_drive.bas"
RUN
```

環境によっては、ファイル名や読み込み方法が異なる場合があります。エミュレータを使う場合は、テキスト形式の BASIC プログラムを読み込める形式に変換するか、エミュレータ側の貼り付け・ロード機能を使ってください。

ブラウザ版は TypeScript をビルドしてから、ローカルサーバーで起動します。

```sh
npm run build
```

```sh
python3 -m http.server 8000 -d public
```

その後、`http://localhost:8000/` を開きます。外部 SVG を参照するため、ブラウザで HTML を直接開くより HTTP 経由での確認を推奨します。

## Firebase Hosting

Firebase CLI を使ってデプロイします。

```sh
firebase login
firebase init hosting
firebase deploy
```

`firebase init hosting` では公開ディレクトリに `public` を指定し、既存の `public/index.html` は上書きしないでください。すでに Firebase プロジェクトを関連付け済みの場合は、`firebase deploy` だけで公開できます。

## ゲームの流れ

1. 起動すると道路と自車が表示されます。
2. 画面中央に `HIT ANY KEY` と表示されたら、任意のキーを押してゲームを開始します。
3. 自車を左右に移動して、道路からはみ出さないように走行します。
4. ステージが進むと、道路の形状や出現する障害物が変化します。
5. 障害物や路肩に衝突するとゲームオーバーです。
6. `Try again [ Y or N ]?` と表示されたら、`Y` で再挑戦、`N` で終了します。

## 操作方法

| 操作 | 内容 |
| --- | --- |
| 左方向 | 自車を左へ移動 |
| 右方向 | 自車を右へ移動 |
| 任意のキー | タイトル表示からゲーム開始 |
| `Y` | ゲームオーバー後に再挑戦 |
| `N` | ゲームオーバー後に終了 |

左右移動はプログラム内で `STICK(0)` を使って判定しています。実機やエミュレータの設定に応じて、カーソルキー、テンキー、ジョイスティックなどに割り当ててください。

## ルール

- 自車は画面下側に表示され、道路は上から下へ流れていきます。
- 道路の端、対向車、障害物にぶつかるとミスになります。
- 走行を続けるとスコアが加算されます。
- 一部の区間ではボーナスアイテムが出現します。
- 小さいボーナスは `+100` 点、大きいボーナスは `+1000` 点です。
- 区間を突破すると、スコアに応じたボーナスが加算されます。
- ハイスコアは実行中のみ保持され、初期値は `20000` 点です。

## ステージ構成

ゲームは複数の走行パターンを順番に繰り返します。

| 区間 | 内容 |
| --- | --- |
| 壁出現区間 | 壁が出現する区間 |
| 岩出現区間 | 岩が出現する区間 |
| 氷の道区間 | 通れる位置が左右に揺れる区間 |
| ドラム缶区間 | 横長のドラム缶が道路上に出現する区間 |
| 対向車出現区間 | 対向車が左右に動きながら出現する区間 |
| ボーナス出現区間 | アイテムを取って追加点を狙う区間 |

## 画面表示

| 表示 | 内容 |
| --- | --- |
| `HIGH SCORE` | 現在のハイスコア |
| `YOUR SCORE` | 現在のスコア |
| `ROAD` | 現在の進行区間 |
| `BONUS` | 区間突破時のボーナス加算 |

## 攻略のヒント

- 画面下の自車だけでなく、少し上の道路状況を見て早めに左右へ移動すると避けやすくなります。
- ボーナス区間ではアイテムを狙いすぎると路肩に接触しやすいため、中央寄りの位置を保つと安定します。
- 追跡車区間では相手の横移動に合わせて大きく避けるより、道路中央付近で小さく調整すると生存しやすくなります。

## 開発メモ

- キャラクタパターンは `DEFCHR$` で定義されています。
- 自車、障害物、道路端、ボーナスアイテムは独自キャラクタで描画されています。
- スコア表示や当たり判定は、画面上のキャラクタを参照する `CHARACTER$` を使って処理されています。
- サウンド効果には `PLAY`、`SOUND`、`BEEP` が使われています。
